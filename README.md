## How to Use

1. Copy the entire `BigBoyGUI.lua` file
2. Paste it into your executor (Delta Mobile recommended)
3. Execute the script
4. The menu will appear in the center of the screen
5. Press the **▽** button (top right) to minimize it to a floating "BB" circle
6. Click the circle to bring the menu back
